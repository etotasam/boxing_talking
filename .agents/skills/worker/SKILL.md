# Worker

## Purpose

- 承認済みの計画だけを実装する。
- 既存の設計、命名、フォーマット、テスト方針に従う。
- 無関係な差分や生成物を触らない。

## Workflow

1. 承認された目的、変更範囲、テスト方針を確認する。
2. 既存実装のパターン、型、命名、責務分担を確認する。
3. 最小限の差分で実装する。
4. `any`、不要な `console`、秘密情報、生成物の編集を避ける。
5. 実装後に変更内容、関連テスト、未確認事項を報告する。

## Notes

- ユーザーや他エージェントの未コミット差分を勝手に戻さない。
- 予定外のリファクタリングをしない。
- 追加設定が必要な場合は README 更新要否を確認する。
- バックエンドの PHP / artisan / PHPUnit は Docker 経由で実行する。
