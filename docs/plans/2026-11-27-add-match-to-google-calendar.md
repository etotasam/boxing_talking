# 試合情報を Google カレンダーに追加

## Goal

開催予定の試合情報ページから、対戦カード・開催日・会場が入力済みの Google カレンダーの予定作成画面を開けるようにする。ユーザーが「保存」を押すと、試合当日だけの終日予定が登録される。

## Tasks

- [ ] 開催予定ページの日時・会場欄の下に「Google カレンダーに追加」を配置し、対戦カード・開催日・会場を含む予定作成 URL を生成する。
- [ ] 開催予定ページと過去試合ページで表示条件を確認するテストを追加する。予定作成リンクのパラメータをデコードし、日本語や記号を含む対戦カードと会場、月末・年末をまたぐ終了日を確認する。
- [ ] 関連する `MatchInfo` と `MatchView` のテストを実行する。PC・スマホでリンクを開き、未ログイン時の遷移と、保存すると試合日のみ終日予定が入ることを確認する。
- [ ] Reviewer subagent による最終レビュー。

## Scope and Impact

- 対象は開催予定の試合情報ページ。過去試合ページも試合表示部品を共有するため、開催予定ページから表示を有効にする。
- 既存の試合データを使うフロントエンド変更。API・DB・認証設定の変更は不要。他カレンダーへの対応と延期・中止の自動反映は対象外。

## Approach and Rationale

- Google の予定作成リンクを使う。Calendar API での直接登録には OAuth の同意画面と書き込み権限が必要で、一般公開時は審査が生じうる。ユーザーが Google 側で保存する要件ならリンクで足り、実装と基本確認は半日〜1日が目安。
- 試合データは日付単位なので、開催日を開始日、その翌日を終了日として `dates` に渡し、当日だけの終日予定にする。タイムゾーン変換で日付がずれないよう暦日として処理し、対戦カードと会場は `URLSearchParams` でエンコードする。
- 保存済みの予定には延期・中止が自動反映されない。Google 側の画面遷移は端末やログイン状態で変わるため、実機で確認する。
