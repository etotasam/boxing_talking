# 計画文書の整理案

## Goal

元worktreeの未保存の統合記録を保護し、現在の計画・保留事項と過去の実行記録を見分けられる構成にする。ユーザーが本案の実行と元worktreeでの作業を承認済み。実施結果は末尾へ記録する。

## Background / Context

- 2026-11-02 JST、元worktreeの`codex/laravel-php-upgrade`、HEAD `84262908`で調査。
- 本書追加前の文書は38件（tracked37、未追跡のP1〜P3統合文書1）。Laravel/PHP18、UI/Query3、P1〜P4の個別計画・統合記録15、継続用全体計画・P4j保留調査2に分類できる。
- 未コミットは全体計画・P3計画の追記、未追跡のP1〜P3統合記録。別の未追跡`.codex/environments/`は対象外とし、中身を参照しない。実環境の.envも参照しない。
- 全体計画のCurrent Progressに最新の統合完了説明と過去の未統合説明が併存し、Next/残課題/版情報にも古い状態が残る。追加追記を重ねるだけでは現状を読み違えやすい。
- plans内のMarkdown相対リンク75件は現在全て解決する。frontend/README.mdのP3リンク、backend/README.mdのLaravel計画・S9リンク、および文中のパス記載も移動の影響対象。
- 未チェックは実作業の残件とは限らない。Laravel全体計画の8項目は各段階の共通手順。旧統合計画の3項目は後続記録で完了を確認できる。一方Query移行のブラウザー確認は末尾で実施範囲を限定しており、全面的な画面確認済みへ書き換えない。

## Scope

### In Scope

- まず既存の未保存の統合記録3件を、内容整合・Reviewer確認後に独立した文書commitで保存する。
- docs/plans/README.mdを新設し、現在の計画、保留事項、履歴を探す入口とする。
- 全体計画とP4j調査を直下に保持し、残り36文書をarchive配下の3テーマへ移動する。既存の日付とファイル名は維持する。
- 現在の全体計画の進捗表・次の作業・残課題・版情報を同じ時点へ揃え、詳細な旧進捗説明を履歴欄へ集約する。P1〜P3の保存前追記は統合記録への参照へまとめるが、固有の事実・制限・証跡参照は残す。
- archiveの意味は「過去の計画・実行記録」。全項目の解決・本番公開可・証跡保存済みを意味しない。冒頭に記録時点・後続文書への参照を付け、当時の結果や未確認範囲を保持する。
- ファイル移動に伴うMarkdownリンクと文書中のリポジトリ相対パスを更新する。過去の実行コマンド・絶対パス・branch名は履歴として保持する。

### Out of Scope

アプリ/依存/DB/Composeの変更、実環境設定の参照、ブランチ/worktree/stash削除、Git管理外の証跡・SQL・バックアップの移動や削除、push、本番反映。MySQLの新worktreeや実装計画は今回作らない。脆弱性情報の再調査はせず、監査値は確認日を付けた過去の結果として扱う。

## Impact Area

docs/plans、frontend/README.md、backend/README.mdの参照先のみ。実装・開発規約・skillのPlan Document作成先は変更しない。提案中の本書は直下に置き、完了後のarchive移動は別途判断する。

## Options

| 案 | 利点 | 欠点・リスク |
| --- | --- | --- |
| A: 配置は維持し目次と現状だけ整理 | リンク変更が少ない | 直下の38文書が残り、現行/履歴を一覧で判別しにくい |
| B: 現行2文書＋目次、履歴はテーマ別archive | 現在の作業と根拠を探しやすく、個別記録も残せる | 移動に伴う相対リンク・README参照の修正が必要 |
| C: 過去文書を削除・数冊へ統合 | ファイル数が最も減る | 承認理由・検証制限・復旧情報・参照アンカーの喪失リスクが高い |

## Decision

Bを第一候補とする。既存記録は削除・大幅合冊せず、入口と現状説明を簡潔にする。

```text
docs/plans/
  README.md                                  # 現行・保留・履歴への目次
  2026-10-22-dependency-runtime-update.md      # P0〜P6の現状と方針
  2026-11-02-frontend-moderate-advisories.md    # P4保留・再評価条件
  2026-11-02-plan-documents-organization.md    # 本提案（実行中のみ）
  archive/
    frontend-features/                       # UI変更・Query移行の3文書
    laravel-php/                             # S0〜S9・統合の18文書
    dependency-runtime/                      # P1〜P4個別・統合の15文書
```
