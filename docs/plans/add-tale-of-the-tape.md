# Add Tale of the Tape

## Goal

試合詳細画面に、赤・青コーナーの選手情報を左右で比較できる Tale of the Tape を追加する。

## Background / Context

現在の試合詳細画面には、選手名、戦績、国籍を表示する選手概要と勝敗予想があるが、年齢、身長、リーチ、スタイルを直接比較する表示がない。既存の未使用コンポーネントには各値の表示ロジックがあるため、その仕様と既存定数を引き継ぐ。

## Scope

### In Scope

- Tale of the Tape の独立コンポーネントを追加する。
- 年齢、身長、リーチ、スタイルを赤・青コーナーの3列比較表で表示する。
- モバイル・PCの両方で収まるレスポンシブなスタイルにする。
- 公開される表示内容を検証するコンポーネントテストを追加する。

### Out of Scope

- 各項目へのアイコン追加。
- API、バックエンド、DB、型定義の変更。
- 選手概要や勝敗予想のデザイン変更。

## Impact Area

- 試合詳細画面の `MatchInfo`。
- Tale of the Tape の新規コンポーネントとテスト。
- API、DB、設定への影響はない。

## Options

### Option 1: BoxersData に直接実装する

- メリット: 新規コンポーネントを追加せずに実装できる。
- デメリット: 選手概要と比較表の責務が混ざり、後からアイコンを追加する際にも変更箇所が大きくなる。
- リスク: コンポーネントが肥大化し、単体テストが難しくなる。

### Option 2: TaleOfTheTape として分離する

- メリット: 表示・値整形の責務が明確で、単体テストと将来のアイコン追加が容易になる。
- デメリット: ファイルが増える。
- リスク: props の追加が必要だが、既存の選手・試合日データのみで完結する。

## Decision

Option 2 を採用する。

## Rationale

比較表は選手概要とは独立したUIであり、専用コンポーネントにすることで責務、テスト容易性、将来の拡張性を保てる。既存データを props で受け取るだけのため、影響範囲も限定できる。

## Test Plan

- 両選手の年齢、身長、リーチ、スタイルが対応する列に表示されることを保証する。
- 身長とリーチに `cm` が付くことを保証する。
- 身長・リーチが未設定の場合に `-` が表示されることを保証する。
- 既存の試合詳細テストを実行し、周辺表示に回帰がないことを確認する。
- lint と build を実行し、静的検査と型検査を通過することを確認する。

## Risks

- 長いスタイル名が狭い画面で折り返される可能性があるため、3列幅と文字サイズをモバイル基準で調整する。
- 年齢は既存仕様に合わせ、予定試合は現在時点、過去試合は試合日時点で算出する。
